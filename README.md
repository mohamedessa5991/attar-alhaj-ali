# عطارة الحاج علي - نسخة Windows

هذه النسخة مجهزة للتشغيل كتطبيق Electron مستقل عن Chrome/Edge.

## حفظ البيانات
البرنامج يعمل كتطبيق سطح مكتب، وبيانات Web Storage الخاصة به تحفظ في مجلد بيانات التطبيق الخاص بالمستخدم بواسطة Electron، وليس في بيانات متصفح خارجي.

> ملاحظة: إذا كانت الواجهة الحالية تعتمد على localStorage، فإن البيانات ستبقى مرتبطة بملف تعريف تطبيق Electron على نفس الجهاز. عند نقل البرنامج لجهاز آخر لن تنتقل البيانات تلقائيًا، لذلك يُنصح باستخدام Backup/Restore لنقل البيانات.

## البناء
- `npm install`
- `npm run dist`

GitHub Actions يقوم بالبناء تلقائيًا وإخراج ملف EXE كـ Artifact.
